Project Portfolio

Automated Syringe Detection & Counting System

Halcon MVTec 24.12 Deep Learning Instance Segmentation HDevelop Computer Vision

Overview

Developed an automated computer vision system using Halcon MVTec Deep Learning Tool 24.12 to detect and count syringes in pharmaceutical production trays in real-time. The system uses instance segmentation to identify filled versus empty spots in uniform trays holding 100 syringes in various configurations and inconsistent lighting.

Problem

Manual counting of syringes in production trays was slow, error-prone, and inefficient. Each tray holds 100 syringes in fixed positions and required manual verification by operators. Manual counting between shifts led to numerous deviations costing significant delays and money.

Solution

  • Trained instance segmentation model on live streaming snapshots with data augmentation
  • Integrated webcam for real-time live detection in HDevelop
  • Live syringe counting display for facilitating operator visual understanding
  • Automated documentation of detection results to CSV dated with timestamps and tray numbers

Results

Syringe Detection Precision: 100%

Syringe Detection Recall: 100%

Processing time: 526.208 ms per tray

Eliminates human counting and documentation errors
