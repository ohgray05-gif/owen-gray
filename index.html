Project Portfolio

BLAST-VIS: Barcode Labeling Automated Syringe & Tray Visual Inferencing System

Halcon MVTec 24.12 Deep Learning Instance Segmentation PowerShell ZPL/Zebra Printing Web GUI 21 CFR Part 11

Overview

BLAST-VIS is a full-stack automated visual inspection platform for pharmaceutical manufacturing. It combines a Halcon deep learning detection engine, a PowerShell-hosted browser GUI, Zebra label printing, and 21 CFR Part 11-aligned features — designed for deployment as browser-only thin clients with zero install on operator PCs.

Results & Output

Detection Precision/Recall: 100%  |  Processing time: 526ms per tray  |  Designed to eliminate manual counting and documentation errors

Generates: signed batch reports, audit logs, per-tub label and tub report, and saved processed images.

Problem

Manual syringe counting across 100 and 160 position tubs was slow and error-prone, causing production deviations, delays, and compliance risk during shift handoffs.

Solution

  • Trained instance segmentation model with 100% precision/recall and per-detection confidence scoring
  • Built browser-based web GUI with live webcam feed, real-time dashboard, and anomaly detection (flags tubs <90)
  • Implemented device-locked batch ownership with dual operator/approver e-signature sign-off and session-based authentication
  • Integrated Zebra ZT411 label printing via ZPL/TCP with Data Matrix barcodes and offline fallback
  • Architected job queue system with multi-batch concurrency and recipe-based model switching
  • Built 21 CFR Part 11-aligned audit trail with append-only JSONL logging, batch reports, and per-tub HTML reports with QR codes and processed images

Defect Detection Inspection Viewer & Categorization System

Halcon MVTec Deep Learning PowerShell Web GUI Image Processing Recipe Development

Overview

A browser-based inspection viewer and tally system built to review defect detection results from a Halcon AI model. The tool displays raw and processed multi-view images side-by-side with pass/fail breakdowns by defect type, giving engineers a fast way to visually audit AI detections across an entire batch.

Results & Output

Streamlined defect review workflow across stainless steel and glass defect categories, enabling faster, more organized recipe creation and parameter tuning for the vision model.

Generates: per-item pass/fail summary table, reject rate tracking, and categorized defect counts across the batch.

Problem

Building and tuning defect detection recipes required manually sifting through hundreds of raw and processed images per batch with no organized way to categorize defect types, slowing down recipe creation and parameter adjustments.

Solution

  • Built a PowerShell-hosted web GUI server displaying 4 synchronized views per item with raw/processed toggle
  • Added per-item navigation with live inspection results table categorizing stainless steel vs. glass defects
  • Automated folder-based batch loading with real-time processing progress tracking
  • Defect categorization to accelerate recipe creation and reduce false reject tuning time
